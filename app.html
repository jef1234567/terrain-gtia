Terrain GTIA

Aide à l'analyse au niveau GTIA. Valeurs fictives, démonstrateur.
1. TerrainAnalyser le terrain d'une zone : mobilité par arme, franchissements, couverts, vues. Produit le fichier terrain. 2. EnnemiPlanification (à froid) : l'ennemi attendu, ses axes, à quelle heure il passe où. Conduite (à chaud) : après un contact, où est le reste, quelles zones survoler. Doctrine fictive. 3. RadarsTrois modes : Ami (notre réseau de radars : ce qu'il voit selon le relief, les forêts et le bâti, ses trous, les meilleurs emplacements) ; Ennemi (zones de défilement et itinéraires défilés face à ses radars) ; Contre-batterie (d'où nos tirs sont repérés, d'où un tir ennemi est localisé). Bibliothèque en sources ouvertes. 4. Implantation (chars)Où placer un char pour avoir le plus de champ de tir utile, d'après le terrain.
Installer sur Android : ouvrez cette page dans Chrome, menu ⋮ puis « Installer l'application » (ou « Ajouter à l'écran d'accueil »). Les outils s'ouvrent ensuite comme une application, même sans réseau ; seul le fond de carte demande une connexion.
Données : les zones analysées et les réglages restent sur cet appareil. Pour passer d'un outil à l'autre, les outils reprennent la dernière zone ouverte ; sinon, utilisez les boutons « Exporter » et « un fichier .json » de chaque outil.
